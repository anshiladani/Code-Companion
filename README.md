**Code Companion – AI-Powered Personalized Coding Learning Platform**

**Project Overview:**
Code Companion is a web-based learning platform designed to help beginners master programming from foundational syntax to advanced problem-solving. By leveraging Machine Learning and an integrated AI assistant, the platform analyzes individual user performance to deliver customized coding problems, adaptive difficulty scaling, and contextual, step-by-step guidance.

**Core Features:**
__Beginner-Friendly Roadmap: __
Structured progression starting from core concepts like variables, loops, and functions.

_Adaptive Difficulty Progression:_
System automatically tunes problem difficulty based on real-time user performance data.

_Personalized ML Recommendations: _
Tailored coding challenges recommended by an underlying Machine Learning framework.
_Integrated Online Code Editor: _

Built-in compiler supporting multiple programming languages for direct in-browser execution.
_Intelligent AI Assistant: _

Provides automated error explanations, hints, and targeted coaching without revealing direct solutions.
_Performance Dashboard: _ 

Extensive analytics interface to track individual progress and conceptual weak points.
