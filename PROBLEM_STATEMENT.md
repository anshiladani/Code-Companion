# Problem Statement

## Current Challenges
Many students face difficulties in learning programming because they lack proper guidance, practice strategy, and personalized learning resources. Existing coding platforms provide problems for practice but are mainly focused on competitive programming and do not effectively support beginners.

## Proposed Objectives
Code Companion aims to address these issues by developing an AI-based coding learning platform that helps students learn programming from basic concepts to advanced problem-solving. The system provides:
* Personalized coding problems based on individual skill levels
* Adaptive difficulty progression using Machine Learning
* Contextual AI-based hints and error explanations to improve students' coding skills independently
