# Project Requirements

## 1. Functional Requirements
* **User Authentication**: Secure student registration, login, and profile tracking.
* **Interactive Code Workspace**: An integrated online code editor and compiler supporting multiple programming languages.
* **Adaptive Problem Engine**: A Machine Learning module that automatically scales problem difficulty based on real-time performance analysis.
* **AI Coding Assistant**: An automated assistant that analyzes compilation errors and provides hints without giving away the final solution.
* **Performance Dashboard**: Visual metrics tracking user progression, active streaks, and language proficiency.

## 2. Non-Functional Requirements
* **Usability**: Intuitive, beginner-friendly frontend UI built using modular React components.
* **Performance**: Code execution and AI hint generation should complete within 3 seconds of a user request.
* **Security**: Sandbox execution environment for user-submitted code to prevent malicious system-level commands.
