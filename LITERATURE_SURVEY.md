# Literature Survey

This survey reviews existing platforms and research to guide the development of Code Companion.

## 1. Existing Platforms
* **LeetCode**: Excellent for advanced users and technical interview preparation. However, it lacks a structured learning path for true beginners and features a steep learning curve.
* **HackerRank**: Offers structured language proficiency tracks, but its problem progression is static and does not dynamically adapt to a user's real-time performance gaps.

## 2. Research Foundations
* **AI-Based Adaptive Learning Systems**: Research indicates that personalized problem-scaffolding significantly reduces drop-out rates among novice programmers.
* **Automated Programming Education**: Utilizing machine learning models to classify code error patterns allows for automated, non-revealing hints that encourage independent troubleshooting.

## 3. Identified Gaps & Code Companion's Edge
Most traditional platforms focus heavily on competitive programming. Code Companion bridges this gap by focusing strictly on beginner fundamentals, using an ML model to automatically scale difficulty, and using generative AI to provide conceptual hints rather than direct solutions.
